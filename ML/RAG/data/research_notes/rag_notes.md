# RAG Research Notes

RAG(Retrieval-Augmented Generation)는 외부 지식을 검색한 뒤, 검색 결과를 근거로 답변을 생성하는 방식이다.
일반적인 흐름은 문서 로딩, 청크 분할, 임베딩 생성, 벡터 저장소 적재, 질의 시 관련 청크 검색, LLM 답변 생성 순서로 구성된다.

실무에서는 단순 벡터 검색만 쓰지 않고, BM25 같은 키워드 검색을 함께 사용해 하이브리드 검색을 구성하기도 한다.
사용자 질문이 매우 구체적이거나 문서 안의 정확한 표현을 찾는 경우에는 키워드 검색이 유리할 수 있다.
반대로 질문이 문맥 의미 중심이거나 표현이 바뀐 경우에는 벡터 검색이 더 강할 수 있다.

면접 관점에서는 "왜 해당 검색 방식을 선택했는가"를 설명하는 것이 중요하다.
예를 들어 개념 설명 질문은 벡터 검색, 특정 용어나 약어가 포함된 질문은 BM25 또는 하이브리드 검색으로 분기했다고 설명할 수 있다.
