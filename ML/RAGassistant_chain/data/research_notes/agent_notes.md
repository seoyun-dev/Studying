# Agent Research Notes

에이전트 시스템은 사용자의 질문을 보고 필요한 도구를 선택하거나 여러 단계를 거쳐 답을 구성한다.
질문이 내부 연구 문서만으로 답할 수 있는지, 외부 최신 정보가 필요한지를 먼저 판단하는 라우팅 단계가 핵심이다.

예를 들어 "내 연구 노트에서 RAG 평가 방법을 정리해줘"는 내부 문서 검색만으로 답할 수 있다.
하지만 "최근 공개된 RAG 평가 트렌드와 내 노트를 비교해줘"는 외부 검색이 함께 필요하다.

이처럼 질문 유형에 따라 검색 대상을 다르게 선택하면 비용과 응답 품질을 함께 관리할 수 있다.
이 로직은 간단한 규칙 기반으로도 만들 수 있고, LLM을 이용한 분류기로도 확장할 수 있다.
